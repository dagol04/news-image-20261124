A newspaper front page that sums up Tuesday 24 November 2026 in one image: the drone strike on the Kyiv region (and a Russian cargo ship ablaze off Finland), the search going on after the factory fire in Banten, Indonesia, the new India–Nepal rail link, the COP31 fallout, thousands marching in Lisbon against the cost of living, Wall Street sliding after the midterm wins — and the day's sport. Drawn programmatically in pure Node.js: a custom rasterizer, a hand-written 5×7 bitmap font and a hand-rolled PNG encoder. No network, no dependencies, byte-identical output on every run.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
